⭐ **EventMate – Smart Event & Venue Management Platform**

A lightweight full-stack web application built to simplify event booking, venue scheduling, and organizer-attendee interaction.
Developed using **React, Spring Boot, and MySQL** with real-time validation and a clean, responsive UI.

---

✅ **Key Features**

* 🔐 Role-based Login (Admin & User)
* 🗓️ Create, update, or cancel events anytime
* 🏛️ Add and track venue availability in real time
* 📸 Assign photographers to events
* 📍 Search events by city, state, or category
* 🧾 Instant booking with backend checks
* 📱 Fully responsive UI with Tailwind + ShadCN

---

✅ **Tech Stack**

| Layer    | Technologies                         |
| -------- | ------------------------------------ |
| Frontend | React JS, Axios, Tailwind CSS        |
| Backend  | Spring Boot, Spring Data JPA, Lombok |
| Database | MySQL                                |
| Tools    | Postman, Git, Maven, npm             |

---

## ✅ **Architecture**

```
React Frontend  ⇄  Spring Boot REST API  ⇄  MySQL Database
```

---

✅ **Quick Setup**

  🔧 Backend

```bash
cd EVENTMATE_BACKEND
mvn spring-boot:run
```

  🎨 Frontend

```bash
cd EVENTMATE_FRONTEND
npm install
npm start
```
